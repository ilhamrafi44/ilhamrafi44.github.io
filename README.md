# ilhamrafi44.github.io

Portfolio for **Muhammad Ilham Rafiannandha** ("Bonsky") — Senior Full Stack Engineer, Jakarta.
Live at **https://ilhamrafi44.github.io**

Static. No build step, no framework, no dependencies — GitHub Pages serves these files directly.

```
index.html          markup + the inline cat/icon <symbol> sprite
css/base.css        design tokens, reset, scroll-reveal
css/components.css  buttons, cards, marquee, terminal, cats
css/sections.css    per-section layout + responsive
js/i18n.js          EN/ID dictionary (97 keys, kept at parity)
js/app.js           language, theme, menu, reveal, counters, scroll cat
```

**Design.** Neo-brutalism: 3px black outlines, hard zero-blur offset shadows, flat saturated
colour, Archivo Black display type. Light and dark, following the system preference until you
override it.

**Language.** English and Indonesian. The Indonesian is not a translation — the jokes are
rewritten in the register people actually speak, because a literal translation of a joke stops
being a joke.

**Cats.** There are cats. Her name is Cimol. She is orange. Every cat is inline SVG driven by
CSS transforms, and every one of them holds still if you have `prefers-reduced-motion` set.
